📌 Basic NumPy Functions
np.array() → Creates a NumPy array from a list or tuple.
Example: arr = np.array([1, 2, 3])

np.zeros() → Creates an array filled with zeros.
Example: arr = np.zeros((3, 3))

np.ones() → Creates an array filled with ones.
Example: arr = np.ones((2, 2))

np.arange() → Creates an array with evenly spaced values within a specified range.
Example: arr = np.arange(0, 10, 2)

np.linspace() → Creates an array with a specified number of equally spaced values between two points.
Example: arr = np.linspace(0, 1, 5)

np.random.rand() → Generates an array of random numbers between 0 and 1.
Example: arr = np.random.rand(2, 3)

np.random.randint() → Generates random integers within a specified range.
Example: arr = np.random.randint(0, 10, (2, 3))

np.reshape() → Changes the shape of an existing array.
Example: arr = np.reshape([1, 2, 3, 4], (2, 2))

np.ndim() → Returns the number of dimensions of an array.
Example: arr.ndim

np.shape() → Returns the shape (dimensions) of an array.
Example: arr.shape
------------------------------------------------------------------------------------------------------------------
📌 Intermediate NumPy Functions
np.sum() → Calculates the sum of all elements in an array.
Example: arr = np.sum([1, 2, 3])

np.mean() → Calculates the mean (average) of all elements.
Example: arr = np.mean([1, 2, 3])

np.median() → Calculates the median of the array.
Example: arr = np.median([1, 2, 3])

np.std() → Calculates the standard deviation.
Example: arr = np.std([1, 2, 3])

np.min() → Returns the minimum value in an array.
Example: arr = np.min([1, 2, 3])

np.max() → Returns the maximum value in an array.
Example: arr = np.max([1, 2, 3])

np.argmin() → Returns the index of the minimum value in an array.
Example: arr = np.argmin([1, 2, 3])

np.argmax() → Returns the index of the maximum value in an array.
Example: arr = np.argmax([1, 2, 3])

np.unique() → Finds unique elements in an array.
Example: arr = np.unique([1, 2, 2, 3])

np.sort() → Sorts the elements of an array.
Example: arr = np.sort([3, 1, 2])
------------------------------------------------------------------------------------------------------------------
📌 Advanced NumPy Functions
np.dot() → Performs matrix multiplication or dot product of two arrays.
Example: arr = np.dot(a, b)

np.cross() → Computes the cross product of two vectors.
Example: arr = np.cross(a, b)

np.linalg.inv() → Computes the inverse of a matrix.
Example: arr = np.linalg.inv(a)

np.linalg.eig() → Computes the eigenvalues and eigenvectors of a matrix.
Example: arr = np.linalg.eig(a)

np.fft.fft() → Computes the one-dimensional discrete Fourier Transform.
Example: arr = np.fft.fft(a)

np.vstack() → Stacks arrays vertically (row-wise).
Example: arr = np.vstack((a, b))

np.hstack() → Stacks arrays horizontally (column-wise).
Example: arr = np.hstack((a, b))

np.split() → Splits an array into multiple sub-arrays.
Example: arr = np.split(a, 3)

np.concatenate() → Joins multiple arrays together.
Example: arr = np.concatenate((a, b))

np.tile() → Repeats an array multiple times.
Example: arr = np.tile(a, (2, 2))
------------------------------------------------------------------------------------------------------------------
📌 Bonus NumPy Functions
np.random.choice() → Randomly selects elements from an array.
Example: arr = np.random.choice([1, 2, 3], 2)

np.cov() → Computes the covariance matrix.
Example: arr = np.cov(a, b)

np.corrcoef() → Computes the correlation coefficient between two arrays.
Example: arr = np.corrcoef(a, b)

np.sign() → Returns the sign of the elements in the array.
Example: arr = np.sign([-1, 0, 1])

np.gradient() → Returns the gradient (derivative) of an array.
Example: arr = np.gradient(a)

np.polyfit() → Fits a polynomial of a given degree to data.
Example: arr = np.polyfit(x, y, 2)

np.polyval() → Evaluates a polynomial at specified values.
Example: arr = np.polyval([1, 2, 3], x)
